What is Regression, Really?

Apr 9, 2026 32 min read Statistical Modeling, Measurement Error

Introduction

If you have been following this series, you might have noticed something hiding in plain sight: the word “regression” literally means shrinkage toward the mean. This is not a metaphor or a historical curiosity—it is the phenomenon itself, and it turns out to be deeply connected to everything we have been discussing.

In Part 1 of this series, we showed that six different methods for estimating individual means—James-Stein, classical true score estimation, empirical Bayes, ridge regression, and hierarchical models—all converge on the same shrinkage factor: \(B = \sigma^2_{\text{pop}} / (\sigma^2_{\text{pop}} + \sigma^2_{\text{obs}}/n)\). In Part 2, we extended this to the multivariate case, showing that measurement error systematically attenuates correlations and that the matrix-valued shrinkage \(\mathbf{B} = \boldsymbol{\Sigma}_{\text{pop}}(\boldsymbol{\Sigma}_{\text{pop}} + \boldsymbol{\Sigma}_{\text{obs}}/n)^{-1}\) provides the fix.

In this post, we complete the picture. The regression coefficient \(\beta = \text{Cov}(X, Y) / \text{Var}(X)\) is itself a reliability-weighted quantity—when predictors are measured with error, OLS regression coefficients are attenuated by exactly the same shrinkage factor we have been studying all along. We will trace this from Galton’s original discovery through Pearson’s formalization, errors-in-variables models, and multiple regression (where the story becomes considerably more interesting than you might expect), ending with hierarchical Bayesian models that provide a principled solution.

Galton’s Discovery — The Origin of “Regression”

The Historical Dataset

In 1886, Francis Galton published “Regression towards Mediocrity in Hereditary Stature”—a paper whose title describes the phenomenon so precisely that it became the name of an entire statistical method. Galton observed that children of tall parents tend to be tall, but less extreme than their parents. Children of short parents tend to be short, but again less extreme. The children’s heights “regressed” toward the population average, and Galton’s \(\approx 2/3\) proportionality factor is itself a shrinkage coefficient in the sense we have been discussing.

The Math

When both variables are standardized, the regression slope equals the Pearson correlation: \(\hat{\beta}^{(z)} = r_{XY}\). And from Part 2, we know that the observed correlation between two noisy measures is attenuated:

\[r_{XY} = \rho_{\text{true}} \sqrt{\rho_{xx} \cdot \rho_{yy}}\]

So the regression slope is a shrunken version of the true relationship. Galton’s \(\approx 2/3\) factor is an estimate of the correlation between mid-parent and child heights, which is itself a product of the true heritability and the reliabilities of both measures.

Simulation

To evaluate estimators against ground truth—consistent with the approach in Parts 1 and 2—let’s generate data from a known data-generating process where we have a true regression coefficient and measurement error on the predictor:

# Simulation parameters
N_subj      <- 200
n_obs       <- 5       # observations per person per variable
beta_true   <- 0.8     # true regression coefficient (latent X -> Y)
mu_x        <- 68      # population mean of latent X
sigma_x     <- 3       # population SD of latent X (between-person)
sigma_obs_x <- 4       # observation-level SD for X
sigma_eta   <- 3       # residual SD in structural equation

# Generate latent true scores
theta_x <- rnorm(N_subj, mu_x, sigma_x)
theta_y <- beta_true * theta_x + rnorm(N_subj, 0, sigma_eta)

# Generate noisy observations
obs_data <- foreach(i = 1:N_subj, .combine = "rbind") %do% {
  x_obs <- rnorm(n_obs, theta_x[i], sigma_obs_x)
  y_obs <- theta_y[i] + rnorm(n_obs, 0, sigma_eta)
  data.frame(
    subj    = i,
    trial   = 1:n_obs,
    theta_x = theta_x[i],
    theta_y = theta_y[i],
    x       = x_obs,
    y       = y_obs
  )
}

# Compute sample means per individual
subj_summary <- obs_data %>%
  group_by(subj) %>%
  summarize(
    theta_x = unique(theta_x),
    theta_y = unique(theta_y),
    x_bar   = mean(x),
    y_bar   = mean(y),
    .groups = "drop"
  )

# Reliability of X
rho_xx <- sigma_x^2 / (sigma_x^2 + sigma_obs_x^2 / n_obs)

# OLS on sample means
fit_ols <- lm(y_bar ~ x_bar, data = subj_summary)
beta_ols <- coef(fit_ols)[2]

# True regression of theta_y on theta_x
fit_true <- lm(theta_y ~ theta_x, data = subj_summary)
beta_latent <- coef(fit_true)[2]

Pearson’s Formalization — \(\beta\) = Cov/Var as Shrinkage

The Clean Case

In 1896, Karl Pearson formalized Galton’s observations into the framework we now call regression. The population regression coefficient is:

\[\beta = \frac{\text{Cov}(X, Y)}{\text{Var}(X)}\]

When \(X\) is measured without error, OLS gives an unbiased estimate of \(\beta\). No problems there.

Introducing Measurement Error on X

Now suppose we do not observe \(X\) directly. Instead, we observe \(\tilde{X} = \theta + \epsilon\), where \(\theta\) is the true latent predictor and \(\epsilon\) is measurement error. The key decomposition is:

\[\text{Var}(\tilde{X}) = \text{Var}(\theta) + \text{Var}(\epsilon)\]

\[\text{Cov}(\tilde{X}, Y) = \text{Cov}(\theta + \epsilon, Y) = \text{Cov}(\theta, Y)\]

The covariance is unbiased (error is uncorrelated with \(Y\)), but the variance is inflated. Therefore:

\[\hat{\beta}_{\text{OLS}} = \frac{\text{Cov}(\tilde{X}, Y)}{\text{Var}(\tilde{X})} = \frac{\text{Cov}(\theta, Y)}{\text{Var}(\theta) + \text{Var}(\epsilon)} = \beta_{\text{true}} \cdot \frac{\text{Var}(\theta)}{\text{Var}(\theta) + \text{Var}(\epsilon)} = \beta_{\text{true}} \cdot \rho_{xx}\]

The OLS regression coefficient is the true coefficient times the predictor reliability. This is the same signal-over-signal-plus-noise ratio from Parts 1 and 2—\(\sigma^2_{\text{pop}} / (\sigma^2_{\text{pop}} + \sigma^2_{\text{obs}}/n)\)—now showing up in the context of regression.

The Asymmetry

One important subtlety worth highlighting: measurement error in \(Y\) increases the residual variance (and thus widens confidence intervals), but it does not bias \(\hat{\beta}\). Only measurement error in \(X\) causes attenuation. This asymmetry arises because \(X\) enters the denominator of \(\beta = \text{Cov}/\text{Var}(X)\), while \(Y\) enters only the numerator—and as we showed in Part 2, measurement error in the numerator washes out, while error in the denominator inflates it.

Sampling Distribution

To confirm that this is not an (un)lucky simulation seed, we can repeat the simulation many times and look at the sampling distribution of \(\hat{\beta}_{\text{OLS}}\):

n_sims <- 1000

The Standardized Case — Connecting All Three Posts

When both \(X\) and \(Y\) are standardized, the regression slope reduces to the Pearson correlation:

\[\hat{\beta}^{(z)} = r_{XY} = \rho_{\text{true}} \sqrt{\rho_{xx} \cdot \rho_{yy}}\]

Errors-in-Variables — The Measurement Model Perspective

The EIV Model

At this point, it is worth reframing regression as a latent variable problem. The errors-in-variables (EIV) model makes explicit what we have been describing implicitly throughout this post:

Structural equation: \[Y_i = \beta_0 + \beta_1 \theta_i + \eta_i\]

Measurement model: \[\tilde{X}_i = \theta_i + \epsilon_i\]

We observe \(\tilde{X}\), not the latent \(\theta\). This is exactly the measurement model from Parts 1 and 2, now applied to regression predictors. The key reframe is that OLS on observed \(\tilde{X}\) is not estimating the relationship between the true \(\theta\) and \(Y\)—it is estimating a shrunken version of that relationship, attenuated by the predictor reliability.

Reliability Correction

If we know (or can estimate) the reliability \(\rho_{xx}\), we can correct the OLS estimate:

\[\hat{\beta}_{\text{corrected}} = \frac{\hat{\beta}_{\text{OLS}}}{\rho_{xx}}\]

This is the regression analogue of Spearman’s correction from Part 2. And like Spearman’s correction, it is unbiased on average but can have high variance—the same bias-variance tradeoff we have seen throughout this series.

# Reliability-corrected estimate
beta_corrected <- beta_ols / rho_xx

# Sampling distributions: naive OLS vs corrected
beta_corrected_sims <- beta_sims / rho_xx

beta_compare_df <- data.frame(
  beta   = c(beta_sims, beta_corrected_sims),
  Method = rep(c("Naive OLS", "Reliability-Corrected"), each = n_sims)
)

beta_compare_df %>%
  ggplot(aes(x = beta, fill = Method)) +
  geom_histogram(color = "white", bins = 80, alpha = 0.6, position = "identity") +
  geom_vline(xintercept = beta_true, color = "gray40", linewidth = 1.2) +
  scale_fill_manual(values = c("Naive OLS" = "#DCBCBC",
                                "Reliability-Corrected" = "#8F2727")) +
  xlab(expression(hat(beta))) +
  ylab("Count") +
  ggtitle("Naive OLS vs. Reliability-Corrected Estimates") +
  theme_minimal(base_size = 15) +
  theme(panel.grid = element_blank(),
        legend.position = c(0.8, 0.85))

The corrected estimates (dark red) are centered on the true \(\beta\) = 0.8, but with considerably higher variance than the naive OLS (dusty rose). We saw this exact pattern with Spearman’s correction in Part 2—dividing one noisy quantity by another can produce extreme values, so the correction removes bias at the cost of increased variance.

Multiple Regression with Measurement Error

An Important Complication

So far, the story has been straightforward: measurement error on the predictor attenuates \(\beta\) toward zero, and the attenuation factor is the reliability \(\rho_{xx}\). You might reasonably expect the same thing to happen in multiple regression. It does not—at least, not in the simple way you would expect.

With two predictors \(\tilde{X}_1\) and \(\tilde{X}_2\) both measured with error:

\[\hat{\boldsymbol{\beta}}_{\text{OLS}} = (\tilde{\mathbf{X}}'\tilde{\mathbf{X}})^{-1}\tilde{\mathbf{X}}'\mathbf{Y}\]

The matrix \(\tilde{\mathbf{X}}'\tilde{\mathbf{X}}\) has inflated diagonal entries (\(\text{Var}(\theta_k) + \text{Var}(\epsilon_k)\)) but unchanged off-diagonal entries (\(\text{Cov}(\theta_1, \theta_2)\)). This asymmetric distortion of the covariance matrix, once inverted, can push coefficients in either direction—a coefficient can be attenuated, inflated, or even change sign, depending on the correlation structure among the predictors and how reliable each one is.

Intuition

Why does this happen? When two correlated predictors have different reliabilities, the more reliable predictor effectively “steals” variance from the less reliable one during the partialing process that multiple regression performs. This creates suppression-like effects that are qualitatively different from the simple regression case.

Simulation: Two Correlated Predictors

# Multiple regression setup
N_mr        <- 300
n_obs_mr    <- 5
sigma_pop1  <- 3
sigma_pop2  <- 3
rho_x1x2    <- 0.6
beta1_true  <- 0.5
beta2_true  <- 0.5
sigma_eta_mr <- 4

# Varying reliabilities
sigma_obs1_mr <- 4    # moderate reliability for X1
sigma_obs2_mr <- 8    # low reliability for X2

# Population covariance matrix for latent predictors
Sigma_theta <- matrix(c(sigma_pop1^2, rho_x1x2 * sigma_pop1 * sigma_pop2,
                          rho_x1x2 * sigma_pop1 * sigma_pop2, sigma_pop2^2), 2, 2)

# Reliabilities
rho_xx1 <- sigma_pop1^2 / (sigma_pop1^2 + sigma_obs1_mr^2 / n_obs_mr)
rho_xx2 <- sigma_pop2^2 / (sigma_pop2^2 + sigma_obs2_mr^2 / n_obs_mr)

# Simulate data
theta_mr <- MASS::mvrnorm(N_mr, mu = c(0, 0), Sigma = Sigma_theta)
y_mr     <- beta1_true * theta_mr[, 1] + beta2_true * theta_mr[, 2] + rnorm(N_mr, 0, sigma_eta_mr)

obs_mr <- foreach(i = 1:N_mr, .combine = "rbind") %do% {
  data.frame(
    subj = i,
    trial = 1:n_obs_mr,
    theta1 = theta_mr[i, 1],
    theta2 = theta_mr[i, 2],
    y_true = y_mr[i],
    x1 = rnorm(n_obs_mr, theta_mr[i, 1], sigma_obs1_mr),
    x2 = rnorm(n_obs_mr, theta_mr[i, 2], sigma_obs2_mr),
    y  = y_mr[i] + rnorm(n_obs_mr, 0, sigma_eta_mr)
  )
}

summ_mr <- obs_mr %>%
  group_by(subj) %>%
  summarize(
    theta1 = unique(theta1), theta2 = unique(theta2), y_true = unique(y_true),
    x1_bar = mean(x1), x2_bar = mean(x2), y_bar = mean(y),
    .groups = "drop"
  )

# OLS on sample means
fit_mr_ols <- lm(y_bar ~ x1_bar + x2_bar, data = summ_mr)
beta_mr_ols <- coef(fit_mr_ols)[-1]

# True regression on latent
fit_mr_true <- lm(y_true ~ theta1 + theta2, data = summ_mr)
beta_mr_true <- coef(fit_mr_true)[-1]

With \(\rho_{xx,1}\) = 0.74 and \(\rho_{xx,2}\) = 0.41, the OLS estimates are \(\hat{\beta}_1\) = 0.52 and \(\hat{\beta}_2\) = 0.22 (true values: \(\beta_1 = \beta_2\) = 0.5). Notice what has happened—the more reliable predictor (\(X_1\)) has an inflated coefficient, while the less reliable one (\(X_2\)) is more severely attenuated than it would be in simple regression. The measurement error has not just shrunk things toward zero; it has redistributed variance across the predictors in a way that depends on their relative reliabilities and intercorrelation.

How Bias Depends on Reliability and Correlation

# Analytical computation of OLS bias in multiple regression
# For two predictors with equal true betas
rho_grid     <- seq(0, 0.9, by = 0.05)
rho_xx2_grid <- seq(0.1, 0.95, by = 0.05)

bias_grid <- expand.grid(rho_12 = rho_grid, rho_xx2 = rho_xx2_grid)

bias_grid$beta1_ratio <- sapply(1:nrow(bias_grid), function(k) {
  rho_12_k   <- bias_grid$rho_12[k]
  rho_xx2_k  <- bias_grid$rho_xx2[k]
  rho_xx1_k  <- rho_xx1  # fix X1 reliability

  # Observed covariance matrix of sample means
  # Var(x_bar_j) = sigma_pop_j^2 + sigma_obs_j^2 / n = sigma_pop_j^2 / rho_xx_j
  var_x1 <- sigma_pop1^2 / rho_xx1_k
  var_x2 <- sigma_pop2^2 / rho_xx2_k
  cov_12 <- rho_12_k * sigma_pop1 * sigma_pop2  # unchanged by measurement error

  Sigma_obs <- matrix(c(var_x1, cov_12, cov_12, var_x2), 2, 2)

  # Cov(X_obs, Y) = Cov(theta, Y) = beta_true * Sigma_theta columns
  cov_xy <- c(beta1_true * sigma_pop1^2 + beta2_true * rho_12_k * sigma_pop1 * sigma_pop2,
              beta2_true * sigma_pop2^2 + beta1_true * rho_12_k * sigma_pop1 * sigma_pop2)

  beta_ols_k <- solve(Sigma_obs) %*% cov_xy
  beta_ols_k[1] / beta1_true  # ratio of OLS to true for beta1
})

bias_grid %>%
  ggplot(aes(x = rho_12, y = rho_xx2, fill = beta1_ratio)) +
  geom_tile() +
  scale_fill_gradient2(low = "#2166AC", mid = "white", high = "#8F2727",
                       midpoint = 1, name = expression(hat(beta)[1] / beta[1])) +
  geom_contour(aes(z = beta1_ratio), color = "gray30", breaks = 1, linewidth = 0.8) +
  xlab(expression("Correlation between predictors " * rho(X[1], X[2]))) +
  ylab(expression("Reliability of X"[2] * " (" * rho[xx2] * ")")) +
  ggtitle(expression("Bias of " * hat(beta)[1] * " in Multiple Regression"),
          subtitle = paste0("(\u03C1_xx1 = ", round(rho_xx1, 2), " held fixed)")) +
  theme_minimal(base_size = 15) +
  theme(panel.grid = element_blank())

The contour line at 1.0 marks the boundary between attenuation (blue, \(\hat{\beta}_1 / \beta_1 < 1\)) and inflation (red, \(\hat{\beta}_1 / \beta_1 > 1\)). When predictors are uncorrelated (\(\rho_{12} = 0\)), \(\hat{\beta}_1\) is simply attenuated by \(\rho_{xx,1}\) as in simple regression—the familiar story. But when predictors are correlated and have differential reliabilities, \(\hat{\beta}_1\) can be inflated beyond its true value. I think this is genuinely underappreciated in the social sciences, where multiple regression with noisy predictors is the bread and butter of empirical research.

Hierarchical / Bayesian Regression

From Measurement Models to Generative Models

OK, so we have seen that OLS regression coefficients are systematically biased when predictors are measured with error, and that in the multiple regression case this bias can go in unpredictable directions. The errors-in-variables perspective from the previous section makes the problem clear by distinguishing between the latent \(\theta\) and the observed \(\tilde{X}\)—and this distinction naturally suggests a solution. If we acknowledge that predictors are noisy measures of latent constructs, we should model that explicitly. The generative model jointly estimates the latent \(\theta_i\), the regression coefficient \(\beta\), and all variance components:

Structural equation: \[Y_i = \beta_0 + \beta_1 \theta_i + \eta_i\]

Measurement model: \[\tilde{X}_{i,t} \sim \mathcal{N}(\theta_i, \sigma_{\text{obs}})\]

Population model: \[\theta_i \sim \mathcal{N}(\mu_\theta, \sigma_\theta)\]

Because the model separates signal from noise, the posterior for \(\beta\) is centered on \(\beta_{\text{true}}\) rather than the attenuated value. This is the same principle from Parts 1 and 2—hierarchical models produce the right amount of shrinkage because they jointly estimate the variance components that determine it, rather than plugging in point estimates.

Simple Regression: Comparing Methods

Frequentist: lme4

We can approximate the EIV model with lme4 by fitting a hierarchical model with random intercepts per subject on \(X\), and then using the BLUPs as denoised predictors:

library(lme4)

# Regression on denoised estimates

  mutate(x_lmer = theta_hat_lmer,
         y_lmer = theta_y_hat_lmer)

fit_lmer_reg <- lm(y_lmer ~ x_lmer, data = subj_summary)
beta_lmer <- coef(fit_lmer_reg)[2]

Bayesian: brms EIV Model

For a fully Bayesian analysis, we can specify the errors-in-variables model directly in brms. We first fit a measurement model for \(X\) to get posterior estimates of \(\theta_i\), then use these in the structural model:

A Brief Note on Ridge Regression

One connection worth noting: the ridge regression penalty \(\lambda \mathbf{I}\) added to \(\mathbf{X}'\mathbf{X}\) is structurally identical to measurement error inflating \(\mathbf{X}'\mathbf{X}\). Ridge literally behaves as if your clean predictors had measurement error of variance \(\lambda\). This connection completes the circle from Part 1—ridge regularization, which we covered as a shrinkage estimator for means, is the regression analogue of measurement error attenuation. I cover this equivalence in more detail in a previous post.

What This Means for Science

So, why should you care? If you routinely regress outcomes on noisy predictors—summed scores, mean response times, task performance metrics, self-report scales—your \(\hat{\beta}\) underestimates the true effect. The attenuation is exactly \(\rho_{xx}\), the predictor reliability, and since reliability is almost always less than 1 in the social and behavioral sciences, this is happening in essentially every regression that uses imperfect predictors.

The multiple regression case is worse. As we showed above, when you include multiple noisy predictors that are correlated with each other, the bias is no longer a simple attenuation—coefficients can be inflated, attenuated, or even change sign depending on the correlation structure and differential reliabilities. This has substantial consequences for any study using multiple noisy predictors (which is… most studies).

Mediation analysis is especially vulnerable. A typical mediation model involves multiple regression paths, each of which can be attenuated by measurement error. The indirect effect (product of two paths) compounds the attenuation, often dramatically. If each path is attenuated by \(\rho_{xx} = 0.5\), the indirect effect is attenuated by \(0.5 \times 0.5 = 0.25\)—only a quarter of the true value.

The irony of all this is hard to overstate. We named our most widely-used statistical method after the very phenomenon that biases it. “Regression” literally means “shrinkage toward the mean”—which is exactly what measurement error does to regression coefficients. Galton discovered the bias, Pearson formalized it into a method, and generations of scientists have been using that method without accounting for the bias it was named after.

The fix is by now familiar from Parts 1 and 2: use hierarchical models that separate signal from noise, or at minimum, reliability-corrected estimates. When predictors have trial-level data (multiple observations per person per predictor), hierarchical models can extract the latent true scores and estimate regression coefficients that are not attenuated. Even when trial-level data are unavailable, reliability corrections can partially address the problem—though with the variance tradeoff we have seen throughout this series. For complex designs with multiple noisy predictors, the hierarchical approach is strongly preferred, since it handles the unpredictable multiple-regression case naturally.

Conclusion

Across this series, we have traced a single idea through three manifestations:

  • Part 1: The scalar shrinkage factor \(B = \sigma^2_{\text{pop}} / (\sigma^2_{\text{pop}} + \sigma^2_{\text{obs}}/n)\) unifies mean estimation across six methodological traditions.
  • Part 2: The matrix shrinkage factor \(\mathbf{B} = \boldsymbol{\Sigma}_{\text{pop}}(\boldsymbol{\Sigma}_{\text{pop}} + \boldsymbol{\Sigma}_{\text{obs}}/n)^{-1}\) extends the same principle to correlations.
  • Part 3: The regression coefficient \(\hat{\beta} = \beta_{\text{true}} \times \rho_{xx}\), where \(\rho_{xx}\) IS \(B\).

Galton called it regression to the mean. Pearson formalized it as the regression coefficient. Kelley called it reliability. James and Stein called it shrinkage. Ridge regression calls it regularization. Bayesians call it the posterior. If you have been reading this series, you know by now that these are all the same thing :D.
